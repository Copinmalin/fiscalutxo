# Samples

[sparrow-demo.csv](sparrow-demo.csv) contient deux opérations fictives de 2025, un achat et une vente. Il permet de tester l’import Sparrow et la qualification pendant la campagne 2026. Le bouton **Essayer avec un exemple** reprend ce scénario.

## Règles

- Ne jamais commiter de données personnelles réelles.
- Ne jamais commiter de txid personnels non anonymisés.
- Ne jamais commiter d’adresse Bitcoin personnelle.
- Préférer des jeux de données fictifs mais réalistes.

## Sources attendues

- Sparrow Wallet.
- Paymium.
- Bitstack.
- StackinSat.
- Bull Bitcoin si disponible.
- Import manuel générique.
